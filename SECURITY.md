# Security reports

Security reports are welcome for the current desktop Studio Preview, MCP companion and browser preview, as well as the stable v0.4.2 fallback. Fixes target the current maintained release/source line. Older experimental builds and the legacy Python implementation are not separately maintained release lines.

Please [report a vulnerability privately](https://github.com/slimedragonair/SlimeyBeats-EZ-Master/security/advisories/new). Private vulnerability reporting is enabled for this repository. Avoid posting exploit details, private audio or sensitive reports in public issues.

Include the version, reproduction steps, affected input/operation and potential impact. Audio, profile and preset files are input data; describe malformed-file issues with the smallest shareable example. Maintainer response times depend on availability.


**Help → Report a problem** prepares a local reviewed text report; it does not post anything. Ordinary GitHub issues are public. Never attach a recovery store or `.sbrecovery` file to a public issue: those contain audio and private editing state. Use the private route above for vulnerability details.
