# Security reports

The current 0.4.x native Windows line receives fixes. Older experimental builds and the legacy Python implementation are not separately maintained release lines.

Please [report a vulnerability privately](https://github.com/slimedragonair/SlimeyBeats-EZ-Master/security/advisories/new). Private vulnerability reporting is enabled for this repository. Avoid posting exploit details, private audio or sensitive reports in public issues.

Include the version, reproduction steps, affected input/operation and potential impact. Audio, profile and preset files are input data; describe malformed-file issues with the smallest shareable example. Maintainer response times depend on availability.
