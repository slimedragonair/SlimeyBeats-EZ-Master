# Browser Studio stem monitoring

`studio-stem-mixer.js` owns a Web Audio source per immutable stem, channel-preserving balance gains and a common 12 ms gain ramp. Gain/mute/solo changes update the running graph without a worker request, new PCM or transport restart. Mute overrides solo; any solo excludes unsoloed tracks. Editing selects B. The monitor applies conservative sample headroom from cached stem peaks, without A/B loudness matching. Offline rendering remains authoritative for final true-peak protection and exported audio.

`studio-player.js` owns transport position and the exclusive Before/saved-preview/live-stem route. It disconnects the outgoing route and invalidates pending resume requests on pause, Stop and Close. Both player entry points pause the opposite transport before asynchronous resume, including hidden or programmatic Play. Source imports and page transitions also pause the opposite transport.

`studio-worker.js` transfers changed stem PCM only. Read-only bank views in `web/dsp/src/studio.rs` expose identity/length, and `preview_is_mix` follows undo/redo. The page retains only the current bank, enforces the existing 128 MiB bank budget and reuses unchanged AudioBuffers on mix commits. Voice/Repair use their saved rendered PCM until another stem gesture. Update mix preview explicitly commits a controls snapshot before effects, history, promotion or mix export; raw stem export stays immutable. The waveform is labelled as the saved preview.

Run `python -B web/tools/verify_studio_live.py --site <fresh-built-site> --out <ignored-output>` for real output PCM frequency isolation, running-source identity, smoothed stereo balance, pending-resume exclusion and Stop/Close checks. The test-only worklet timestamps capture blocks so queued transition audio cannot contaminate settled-frequency measurements. Then run `verify_studio_browser.py` for the existing Studio editing/import/export/cancellation suite. These headless checks use a synthetic audio device; they do not qualify physical-device latency or subjective sound.
